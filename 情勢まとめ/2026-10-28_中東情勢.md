## 1. イラン戦争の経緯（2026年）

| 時期 | 出来事 |
|---|---|
| 2/28 | 米国（「壮絶な怒り」作戦）とイスラエル（「咆哮する獅子」作戦）がイランを攻撃。**最高指導者アリ・ハメネイ師が殺害される** |
| 開戦直後 | イランが **ホルムズ海峡を外国船に閉鎖**。開戦前、海峡は世界の海上原油取引の約25%、LNGの約20%が通っていた。タンカーの通航はほぼゼロに |
| 3/8 | 専門家会議が、ハメネイ師の息子 **モジタバ・ハメネイ師を新しい最高指導者に選出**。革命防衛隊に近い人物とされる |
| 3/19 | 米国が海峡再開のための航空作戦を開始 |
| 4/8 | パキスタンの仲介で2週間の停戦 |
| 4/13 | イスラマバード協議が決裂し、米国が **イランの港を出入りする全船舶を封鎖** |
| 5/5 | トランプ大統領が護衛作戦「プロジェクト・フリーダム」を停止（パキスタンの要請で交渉を優先） |
| 6月中旬 | 米・イランが14項目の覚書（MoU）に合意（6/14発表、6/17署名と出典により異なる） |
| 7/8 | トランプ大統領が覚書の終了を宣言し、戦闘が再開 |
| 7/14 | 米国が2度目の海上封鎖を開始 |
| 8月 | 覚書が正式に失効 |
| 9月〜 | 限定的な攻撃の応酬が続き、米国は制裁を強化（米議会調査局） |
| 10月 | ホルムズ海峡での船舶攻撃、フーシ派のサウジ攻撃、新たな仲介の動き（後述） |

- この戦争で、湾岸諸国（UAE、サウジ、クウェート、バーレーン）もイランへの攻撃やイラクの武装勢力との交戦に加わったとされる。
- 一方、カタール・UAE・トルコは「自国の領土や領空をイラン攻撃に使わせない」と表明。トルコは米国の軍事行動に反対し、仲介を申し出た。
- 一部のNATO加盟国が米軍の基地使用を拒否したことが、米国による欧州駐留兵力の見直しにつながった。

## 2. ホルムズ海峡と海上の状況（10月）

- **イランの主張**：
  - 「米国が条件を満たすまで海峡は閉鎖を続ける」（10/4）。
  - 海峡で7隻を攻撃したとし、米国に「より広範な対応」を警告（10/22）。
  - 機雷に触れたタンカーが炎上したとも伝えられる。
- **米軍の主張**：
  - 中央軍（CENTCOM）司令官が10/25に海峡を視察し、主要航路にイランの機雷はないと表明。
  - イランはミサイルと無人機で船を攻撃しているが、船舶の約95%は通航できているとしている。
  - この半年で3,000隻以上の商船が米軍の支援を受けて通航した。
- **評価**：米海軍主導の海事センターは、商船への脅威を「深刻」（上から2番目）としている。10月中旬には攻撃が急増し、原油の流れが再び大きく落ち込んだと報じられた（アルジャジーラ、10/14）。
- **経済への影響**：IMFは2026年の原油価格を平均95.74ドルと想定している。供給側の柔軟な対応がなければ110ドル前後になっていたと分析。

## 3. 米・イランの交渉と軍事的圧力

### 3-1. 仲介の動き
- **カタール・パキスタンの「中間案」（10/20）**：報道によれば、パキスタンのムニール陸軍参謀長がテヘランに届けた。
  - イランはIAEAによる **非公表・抜き打ちの核施設査察**を受け入れる。
  - 見返りに米国は、カタールにある **凍結資産60億ドルの利子** をイランが受け取ることを認める。
  - 双方とも前向きに反応したとされるが、匿名の情報源による報道で、公式な確認はない。
- **10/25**：カタールの仲介団がテヘランを訪問し、米国と調整した。
- **地域の代表団**：サウジ・パキスタン・トルコの高官代表団がテヘランを訪れ、戦闘再開を防ごうとしている。
- **10/26**：オマーン外相が、湾岸諸国とイランの **不可侵条約** を提案。ただし、米軍が地域から撤退しない限りイランは応じないとの見方が多い。
- **イランの姿勢**：バガイ外務省報道官は「外交の窓は閉じていない」とし、仲介者を通じてメッセージをやり取りしている。強硬派の中には仲介の効果に深い疑念を示す声もあり、意見が割れている。

### 3-2. 米国・イスラエルの圧力
- トランプ大統領は、中間選挙（11/3）までにイランが方針を変えなければ、米国とイスラエルが「まもなく仕事を終わらせる」と警告したと報じられている。
- 米国は空母をもう1隻派遣し、イスラエルも新たな攻撃計画を準備しているとされる。大統領の命令から96時間以内に大規模作戦を始められる態勢との報道もある。
- 一方でトランプ大統領は「日曜日（10/25）には攻撃しない」と発言し、合意か追加攻撃かを天秤にかけている。

### 3-3. 核問題
- IAEAが最後に確認した **60%濃縮ウランは約440.9kg**（2025年6月時点）。さらに濃縮すれば約10発分に相当する。
- 2025年6月以降、IAEAは主要施設を査察できていない。2026年2月28日以降は保障措置活動もほぼ止まっている。濃縮ウランがどれだけ残り、どこにあるかは不明。
- グロッシIAEA事務局長は、イランが攻撃で損傷した施設を修復しようとした形跡はないと安保理で報告し、査察の受け入れを求めた。
- イラン原子力庁のエスラミ長官は、**濃縮の権利も濃縮ウランの引き渡しも拒否** すると表明している。
- 9/9、IAEA理事会がイランの義務違反を国連安保理に報告したとされる。

## 4. イエメン：フーシ派とサウジアラビアの交戦

- **10/6〜12**：フーシ派が弾道ミサイルと無人機で、サウジの3空港（リヤド、アブハ、ダンマン）を攻撃した。死者は少なくとも20人、負傷者は370人以上（集計により20〜22人）。
  - 最も被害が大きかったのは10/10のリヤド空港への攻撃で、13人が死亡した。リヤド空港は約2週間閉鎖された。運営会社は再開を発表したが、フーシ派は「今も軍事目標だ」と警告している。
- **10/13**：ダーランのサウジアラムコの事務所ビルが攻撃された。サウジは報復としてサヌアの石油施設を攻撃。
- **10/15**：サウジ主導の連合軍が、フーシ派の武器庫・発射台127か所を破壊したと発表。同じ日、国連安保理はフーシ派による航空・エネルギー施設への攻撃を非難する声明を出し、交渉による解決を求めた。
- **10/21**：ダンマンに再び攻撃。
- **10/24**：フーシ派がサウジの3空港・石油施設・空軍基地と、イエメンのアデンを攻撃したと主張。サウジは「聖地も狙われた」としているが、フーシ派は「大うそ」と否定している。
- フーシ派は、イランへの攻撃に米国が加われば米国も標的にすると警告している。
- 紅海では、EUの海上任務「アスピデス」の増強が難航している（追加の軍艦は2隻のみ）。
- エチオピアとエリトリアの対立拡大も、紅海航路のリスクを高めている。

## 5. イスラエル

### 5-1. 総選挙（10/27）
- 出口調査では、**ネタニヤフ陣営もアイゼンコット陣営も過半数（61議席）に届かず**。
- ネタニヤフ首相は「シオニスト有権者の中では右派が決定的多数」と主張し、右派政権を目指している。アイゼンコット氏も勝利を宣言した。
- アラブ系政党は合計16議席前後と過去最高の見込み。投票率は77.7%で、1999年以来の高さ。
- **公式結果は11/4**。連立交渉の長期化や再選挙の可能性もある。選挙結果は、イラン攻撃・ガザ・西岸の政策に直結する。ただし、どちらが勝ってもパレスチナ政策は大きく変わらないとの見方もある（PBS）。

## 6. ガザ

- **停戦の経緯**：
  - 2025年10月10日、トランプ大統領の20項目の和平案に基づいて停戦が発効した。11月には国連安保理が決議で支持し、国際安定化部隊（ISF）の派遣を認めた。
  - 2026年1月、最後の人質の遺体返還が確認され、計画は第2段階に入った。
  - 7/31、「平和評議会」（議長はトランプ大統領）が、**ハマスが段階的に武装解除するロードマップ** を発表した。武装解除が完了したらイスラエル軍が撤退し、ISFと新しいパレスチナ警察が治安を担う。
- **現状（停戦から1年）**：
  - ハマスは「イスラエルが義務を果たさない限り、いかなる段階も実施しない」と表明。武装解除、新たな治安体制、本格的な復興はいずれも未解決のまま。
  - イスラエル軍はガザ内での支配地域をむしろ広げている。アルジャジーラは、平和評議会は恒久的な和平に「失敗した」とする専門家の見方を報じている。
  - ISFとガザの暫定統治機構は展開の準備中で、最初の警察官候補が選ばれた段階。ISFの司令官は米国のジャスパー・ジェファーズ氏。
  - 平和評議会は、本格的な復興はイスラエルの総選挙と米国の中間選挙の後に進むと見込んでいる。
- **人道状況**：イスラエル軍の攻撃で14人が死亡したとの報道（Middle East Eye）。国連の調査委員会は「ジェノサイドは続いている」としている。

## 7. ヨルダン川西岸

- **入植地の拡大と暴力**：ネタニヤフ政権の下で、政府が後押しする入植地拡大と入植者の暴力が急増している。選挙を前に入植者が「既成事実化」を急いでいると報じられた（ワシントン・ポスト、10/5）。
- **主権の拡大**：2026年2月、イスラエル内閣が西岸での主権拡大、土地の接収拡大、入植者によるパレスチナ人からの土地購入を認める決定をした。
- **警察権の移管**：8月、カッツ国防相が西岸の民事上の法執行をイスラエル警察に移す計画を命じた。パレスチナ側の識者の多くは「併合の先兵」とみている。
- **追放**：国連によれば、強制移住は3月時点で3.6万人を超えた。10/24にはヘブロンのエイン・デイル・バハ地区で住民が追い出された。
- オリーブの収穫期に入り、各地で衝突が続いている（10/16 アブ・ファラ、10/19 トゥルムス・アイヤなど）。
- 「併合」という言葉の使い方自体に争いがあり、イスラエル政府は別の説明をしている。

## 8. レバノン

- **2026年の戦争**：イラン戦争と並行してイスラエルとヒズボラが交戦した。レバノンでの死者は4,000人超、避難民は100万人超とされる（集計時点は要確認）。
- **イスラエル・レバノン政府間協議**：1993年以来の最高レベルの協議で、10/20〜22に米フロリダで開かれる予定と報じられた（開催の公式確認はなし）。ヒズボラは参加しておらず、レバノン政府はヒズボラを統制できていない。
- **UNIFIL**：安保理決議2790により **2026年12月31日で活動を終え**、その後1年かけて撤退する。レバノンは延長を求め、後継の国際部隊の設置も要請する方針。EUはレバノン軍を訓練する文民・軍事ミッションを承認した（UNIFILの代わりではない）。
- **緊張の継続**：
  - 10/7、UNIFILの国境監視拠点が小火器で撃たれた（死傷者なし）。
  - イスラエル軍はブルーライン（境界線）の北側で陣地を強化している。
  - ヒズボラはリタニ川の南北で存在感を強め、自爆型無人機の能力を高めて再戦に備えているとされる。イスラエルは、戦争が再開すればレバノンを全面封鎖すると警告したと報じられている。

## 9. シリア

- アフマド・シャラア大統領の政権は **軍の再建** を公然と進めており、イスラエルは新たな脅威として警戒している。
- イスラエルによる越境侵入や攻撃に抗議するデモが起きた（10/23）。
- シリア政府とヒズボラの代表が、緊張緩和のためトルコで秘密裏に直接協議したと報じられた（ロイター）。
- リヤドでの協議で、サウジがフーシ派との戦争へのシリア軍の参加を求めたとの報道がある。シリアは派兵を否定している。
- 国連安保理では、シリアが人道支援の拡大と国際社会との「真のパートナーシップ」を訴えた。

---

## 10. イラク・湾岸諸国

- **イラク**：
  - 親イラン民兵が、クルディスタン地域やバグダッドの米国施設をミサイル・無人機で攻撃している。
  - 10/27には、民兵とみられる無人機2機がバグダッドの米大使館を偵察し、迎撃された。米国がイランを再び攻撃しないよう牽制する狙いとみられる。
  - 民兵組織「イラクのイスラム抵抗」は、サウジ、クウェート、UAE、カタール、バーレーン、ヨルダンの米軍基地・エネルギー施設・空港に少なくとも400回攻撃したとされる（4月時点）。UAEやカタールのイラクへの投資にとって脅威になっている。
- **湾岸諸国**：攻撃を受けながらも、カタールとオマーンは仲介役を担っている。サウジは、フーシ派と交戦する一方でイランに代表団を送るという、二つの路線を同時に取っている。

## 11. 今後の注目点

| 時期 | 出来事 |
|---|---|
| 10月末〜11/3 | 米国の対イラン追加攻撃の有無（中間選挙前） |
| 11/3 | 米中間選挙 |
| 11/4 | イスラエル総選挙の公式結果、その後の連立交渉 |
| 11月 | カタール・パキスタンの仲介案の行方、IAEA査察の可否 |
| 12/31 | UNIFILの活動終了 |
| 随時 | フーシ派とサウジの戦闘、ホルムズ海峡の通航と原油価格 |

### 読み解きのポイント
1. **米国の選挙とイスラエルの選挙が同時に重なる**：トランプ政権は中間選挙前に「合意」か「攻撃」かを決める必要に迫られている。イスラエルの新政権の構成も、対イラン・ガザ政策を左右する。
2. **戦線は「イラン本体」から周辺へ広がっている**：フーシ派対サウジ、イラクの民兵対米国、ヒズボラ対イスラエルと、イランの同盟勢力を通じた戦いが並行している。
3. **核問題が「見えない」状態**：濃縮ウランの所在がわからず、査察もない。仲介案の核心が「抜き打ち査察」なのはこのためで、合意できれば局面が変わる可能性がある。
4. **パレスチナ問題は後回しになっている**：イラン戦争に関心が集まる一方、ガザの武装解除と復興は停滞し、西岸では事実上の併合が進んでいる。
