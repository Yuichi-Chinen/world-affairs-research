# 石油精製と石油製品 — 原油から何が作られるか

- **作成**：2026-11-09
- **きっかけ**：[動画まとめ：ラリー・ジョンソン「トランプ敗北後の戦争リスク」](../動画まとめ/2026-11-06_ラリー・ジョンソン_トランプ敗北後の戦争リスク.md)の「燃料不足と世界経済」の部分
- **注意**：一般的な知識をまとめたものです。数値はおおよその目安で、原油の種類や製油所によって大きく変わります。

## 2. 原油の種類
原油は産地によって性質が違い、どの製品がどれだけ取れるかが変わります。

**重さ（比重）による分け方**
- **軽質原油**：さらさらして軽い。ガソリンやナフサになる成分が多い。例：アメリカのシェールオイル（WTIなど）
- **重質原油**：ねばりがあって重い。重油やアスファルトになる成分が多く、分解装置を使うとディーゼルも多く取れる。例：カナダのオイルサンド、ベネズエラ産
- **中質原油**：その中間。ペルシャ湾の原油（サウジ・イラク・クウェートなど）の多くはこれ

**硫黄の量による分け方**
- **スイート原油**：硫黄が少ない（目安0.5%未満）。精製しやすい
- **サワー原油**：硫黄が多い。硫黄を取り除く設備（脱硫装置）が必要。ペルシャ湾の原油の多くは中質のサワー原油

**動画の話とのつながり**
- アメリカのメキシコ湾岸の大きな製油所の多くは、重質・サワー原油を処理して、ディーゼルなどの値段の高い製品を多く取り出せるように作られています。
- シェール革命でアメリカは軽質・スイート原油を大量に生産するようになりました。ただ、軽質原油を流すとガソリンやナフサが多く取れ、ディーゼルは比較的少なくなります。設備にも合わないため、効率が下がります。
- そのため、アメリカは原油の産出国でありながら重質原油を輸入しています。動画では、その輸入の一部がペルシャ湾から止まったことで、ディーゼル燃料や航空燃料が足りなくなったと説明されています。

## 3. 精製のしくみ
1. **常圧蒸留**：原油を約350℃に熱し、蒸留塔で沸点の違いによって分けます。軽い成分ほど塔の上から、重い成分ほど下から取り出します。
2. **減圧蒸留**：常圧蒸留で残った重い成分を、圧力を下げてさらに分けます。
3. **分解（クラッキング）**：重い成分を熱や触媒で細かく分け、ガソリンや軽油に変えます。
   - 流動接触分解（FCC）：主にガソリンを作る
   - 水素化分解：主にディーゼル燃料やジェット燃料を作る
   - コーカー：一番重い残りかすを分解し、残りは石油コークスにする
4. **改質**：ナフサの性質を変え、オクタン価の高いガソリンの材料にします。
5. **脱硫**：水素を使って硫黄を取り除きます。取り出した硫黄も製品になります。

## 4. 主な石油製品（軽い順）
| 製品 | 沸点の目安 | 主な用途 |
|---|---|---|
| LPG（液化石油ガス：プロパン・ブタン） | 約30℃以下 | 家庭用ガス、タクシー、工業用燃料 |
| ガソリン | 約30〜180℃ | 自動車の燃料 |
| ナフサ | 約30〜180℃ | 石油化学の原料（プラスチック・合成繊維・合成ゴムなど） |
| 灯油 | 約170〜250℃ | 暖房、ストーブ |
| ジェット燃料（航空燃料） | 約170〜250℃ | 航空機の燃料（灯油に近い成分） |
| 軽油（ディーゼル燃料） | 約240〜350℃ | トラック、バス、船、農機、建設機械、発電機 |
| 重油 | 約350℃以上 | 船舶燃料、発電所、工場のボイラー |
| 潤滑油 | 減圧蒸留で取り出す | エンジンオイル、機械油 |
| アスファルト | 最後に残る成分 | 道路の舗装、防水材 |
| 石油コークス・硫黄 | 精製の副産物 | 燃料・電極材料、肥料・化学原料 |

※ 灯油・ジェット燃料・軽油はまとめて「中間留分（ディスティレート）」と呼ばれます。動画で不足が問題になっているのは、主にこの中間留分です。

## 5. 1バレルの原油から取れる量（アメリカの例）
アメリカの製油所では、1バレル（約159リットル）の原油からおおよそ次の量が取れます（米エネルギー情報局 EIA の一般的な説明による目安）。

| 製品 | 割合の目安 |
|---|---|
| ガソリン | 約45% |
| 軽油・暖房用油（中間留分） | 約25〜30% |
| ジェット燃料 | 約10% |
| その他（LPG、重油、アスファルト、石油コークス、潤滑油など） | 残り |

精製すると体積が少し増えるため（精製ゲイン）、合計は原油より数%多くなります。

## 6. なぜ不足が長引くのか（動画の説明の整理）
- **原油の量だけでは決まらない**：必要なのは「どの原油を、どの設備で、何に変えるか」の組み合わせです。原油が余っていても、性質が合わなければ欲しい製品は十分に作れません。
- **民間の製油所は高く買う相手に売る**：アメリカ国内向けの燃料も、ヨーロッパやアジアがより高く買えば輸出に回ります。
- **設備と輸送の被害**：ペルシャ湾の生産設備の修理部品には特注品が多く、超大型タンカーも失われています。動画では、戦争が終わっても回復に少なくとも2年かかるとしています。

## 7. 日本とのつながり（参考）
- 日本は原油の9割以上を中東から輸入しており、ペルシャ湾の原油に合わせた製油所が多くあります。
- 日本の国家備蓄・民間備蓄は合わせて200日分を超える水準とされてきましたが、取り崩しの状況は最新の報道で確かめる必要があります。

### 9.5 まとめ
- **下がりやすい**：原油とガソリン（期待で動く先物市場が先に反応）。
- **下がりにくい**：軽油、ジェット燃料、ナフサ（製油所の被害やロシアの輸出禁止など、物理的な不足）。
- 次に確かめる値：11/9以降の終値、EIA の週次店頭価格（11/10発表）、軽油の値差。
