# ロシアの収入と原油高 — イラン戦争はロシアをどう支えているか

- **作成**：2026-11-13（Claude による調べと整理）
- **材料**：CREA（エネルギー・クリーンエア研究センター）の2026年10月の分析、Energy Intelligence（ロシア財務省の数字）、ロイター報道の要約、国際情勢まとめ・市場レポート
- **注意**：数字は10月中旬〜下旬の報道によるもの。ウラルの価格は「月平均」と「ある週の積み出し港の価格」で大きく違うので、どちらの数字かを書いている。

## 1. 要点（30秒で）
- イラン戦争でホルムズ海峡が閉じ、原油が高くなった。ロシアはその**いちばん大きな受益者の一つ**。
- 10月、ロシアの化石燃料の輸出収入は**1日あたり7億5,400万ユーロ**（前月比+14%）で、2022年12月以来の高さ（CREA）。
- 政府の石油・ガス税収も10月は**9,712億ルーブル（約119億ドル）**で今年いちばん（ロシア財務省）。
- ただし**1〜9月の税収は前年より17%少ない**。年初は原油が安かったため。原油高は「穴を埋めている途中」で、財政が楽になったとまでは言えない。
- 買い手は**中国とインドが過去最高**。制裁の価格上限（1バレル44.1ドル）は、ほとんど効いていない。

### ウラル原油（ロシアの代表的な原油）の値段
- **10月の月平均：101.7ドル**（前月比+13%、2021年10月以降で最高、CREA）。
- ブレントとの差（割引）：23ドル（19%）。9月の24ドル（21%）から少し縮んだ。
- ただし**10月中旬には、積み出し港での値段が約80ドルまで下がった**との報道もある（ロイター）。和平への期待で原油が下がった時期と重なる。

### 政府の税収（ロシア財務省）
- 10月の石油・ガス税収：9,712億ルーブル（約119億ドル）、今年最高。
  - 一部は、3か月ごとに払う石油の利益税が10月に入った分。
- 1〜9月の合計：5兆4,700億ルーブル（約644億ドル）、**前年より17%少ない**。
- 2026年の予算では、石油・ガス収入を8兆9,180億ルーブル（予算全体40兆2,830億ルーブル）と見込んでいる。

## 3. 誰が買っているか（10月、CREA）
| 国・地域 | 金額 | ひと言 |
|---|---|---|
| 中国 | 107億ユーロ | 過去最高。上位5か国の収入の約半分 |
| インド | 64億ユーロ | 過去最高。9割が原油 |
| EU | 22億ユーロ | 半分以上がパイプラインのガス |
| トルコ | 11億ユーロ | |

**中東の原油がホルムズで止まった分を、ロシアの原油で埋めている**という形。中国とインドにとっては、ロシアの原油が「安く手に入る、止まらない原油」になっている。

## 4. 制裁はなぜ効いていないか
- **価格上限**：EUと英国は、ロシアの原油を1バレル44.1ドル以上で運ぶことを禁じている（2026年2月から）。実際の値段は100ドル前後で、上限の倍以上。
- **影の船団（シャドーフリート）**：10月の海上輸送の**60%は制裁対象の船**が運んだ。西側の保険・船を使わないので、上限が届かない。
- CREAの試算では、上限がきちんと守られていれば、10月の海上の原油収入は約17%（18億ユーロ）少なかった。CREAは上限を30ドルに下げるよう提言している。

## 5. ウクライナの攻撃という「逆風」
- ウクライナのドローンが、ロシアの製油所や港を繰り返し攻撃している（キリシ、ウスチ・ルガ、トゥアプセなど）。
- 黒海のトゥアプセ港は、8月以降、石油製品の積み込みがほぼゼロ（CREA）。
- 石油製品の輸出は、前年同月より38%少ない。
- つまり、**原油は高く売れているが、製品（軽油など）は思うように売れていない**。ロシアにとっては「原油で稼ぎ、製品で失う」状態。

## 6. 戦争と交渉にどう効くか（見立て）
- **ロシアが急がない理由の一つ**：収入が戻りつつあるので、ウクライナ和平で領土を譲ってまで急ぐ必要が薄い。11/12 のプーチン氏の強い条件（欧州軍拒否・4州全体）と合わせて考えると筋が通る。
- **イランで合意ができると、ロシアには逆風**：ホルムズが開けば原油が下がり、ロシアの収入と交渉の余裕が減る。ウクライナを支える側から見ると、**イランの和平はロシアへの間接的な圧力**になる。
- **ただし財政は盤石ではない**：1〜9月は前年より17%少なく、戦費もかかる。原油が80ドル台に戻れば、また苦しくなる。
- **日本から見ると**：日本はロシアの原油をほぼ買っていないが、中東の原油に頼るので、ホルムズの閉鎖で値上がりの痛みを受ける側。同じ原油高でも、ロシアは得をし、日本は損をする。
